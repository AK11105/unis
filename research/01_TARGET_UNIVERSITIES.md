# Research Checklist

For each university investigate:

- [ ] Admission requirements
- [ ] Minimum GPA
- [ ] English requirements
- [ ] GRE requirement
- [ ] Application deadline
- [ ] Tuition
- [ ] Living expenses
- [ ] Scholarships
- [ ] Research Assistant opportunities
- [ ] Teaching Assistant opportunities
- [ ] Thesis structure
- [ ] Curriculum
- [ ] AI electives
- [ ] Computer Vision
- [ ] Machine Learning
- [ ] Reinforcement Learning
- [ ] Distributed Systems
- [ ] ML Systems
- [ ] Research Labs
- [ ] Faculty Match (see Faculty Match sheet)
- [ ] Industry collaborations
- [ ] Overall personal rating (/10)
